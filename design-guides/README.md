# เลือกดีไซน์แล้วดาวน์โหลดไฟล์เดียว

ไม่ต้อง clone repo ไม่ต้องรันเว็บ และไม่ต้องใช้ shadcn CLI

1. เลือกดีไซน์จากตารางด้านล่าง
2. เปิดไฟล์ .md แล้วกด **Download raw file** ที่มุมบนของไฟล์ (หากแสดงเป็นไอคอน ให้มองหารูปลูกศรดาวน์โหลด)
3. แนบไฟล์ให้ AI ในโปรเจคของคุณ แล้วบอกส่วนที่อยากใช้

ตัวอย่างข้อความ:

> อ่านไฟล์นี้ แล้วนำเมนู side-nav ของ nong-wang-jai มาใช้กับโปรเจคนี้ ปรับให้เข้ากับโครงสร้างเดิมและคงการทำงานเดิมไว้

แต่ละไฟล์รวมสี ฟอนต์ Layout กติกา ธีม และโค้ด component ครบ ใช้ออฟไลน์หลังดาวน์โหลดได้ โค้ดเป็น React + Tailwind; AI ต้องปรับให้เข้ากับโปรเจคปลายทาง รูปภาพและไฟล์ฟอนต์ไม่ได้ฝังอยู่ใน .md

Repository นี้เป็น Private สมาชิกต้องได้รับสิทธิ์และล็อกอิน GitHub ก่อนดาวน์โหลด

สำหรับผู้ดูแล: เมื่อแก้ registry ให้รัน `npm run export:guides` แล้ว commit ไฟล์ .md ที่อัปเดตไปด้วย
