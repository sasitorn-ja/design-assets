# คู่มือฟีเจอร์ (ไม่ใช่ดีไซน์)

คู่มือ implement ฟีเจอร์ฝั่งระบบ เช่น auth, session, สิทธิ์ และ audit ที่ทีมทำไว้แล้วในโปรเจคหนึ่ง และอยากให้โปรเจคอื่นนำไปใช้ซ้ำ

วิธีใช้เหมือนไฟล์ดีไซน์: เปิดไฟล์ .md → กด **Download raw file** → แนบให้ AI ในโปรเจคของคุณ แต่ละไฟล์มี "Prompt สำหรับส่งต่อ" อยู่ท้ายไฟล์

| คู่มือ | ต้นแบบ | เนื้อหา |
| --- | --- | --- |
| [ระบบปลอมตัว SSO — เข้าใช้งานแทนผู้ใช้ (User Impersonation)](./user-impersonation.md) | RMC Sale Support (S&OP) | ระบบปลอมตัวเป็นผู้ใช้ SSO คนอื่น ให้ Super Admin เปิดแอปในมุมของผู้ใช้อีกคน: พฤติกรรมจริงใน S&OP, สเปกสองตัวตน (actor / effective user), ตาราง PostgreSQL, API start/stop, CSRF, audit, หน้าจอ และ acceptance tests |

สำหรับผู้ดูแล: ไฟล์ในโฟลเดอร์นี้เขียนเอง ไม่ได้สร้างจาก `npm run export:guides` เมื่อเพิ่มไฟล์ใหม่ ให้เพิ่มแถวในตารางนี้และใน `lib/feature-guides.ts` ด้วย
